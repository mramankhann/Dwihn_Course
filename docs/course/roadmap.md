### Session flow

1. **Open the session.** State the purpose, connect it to the learner’s role, and invite a retrieval question.
2. **Teach the concepts.** Explain the session topic and connect it to a realistic, clearly labeled example.
3. **Demonstrate the workflow.** Model the relevant decisions using synthetic material or a confirmed training environment.
4. **Practice together.** Learners complete the session exercise and produce the stated work product.
5. **Check understanding.** Review the knowledge check, correct misconceptions, and name any questions that need an owner.
6. **Close with Q&A.** Answer questions, record policy or configuration questions for the right DWIHN owner, and preview the next session.

Keep Q&A as part of each live session. Continue for as long as learners need to resolve questions and complete guided practice.

Session 2 covers two modules, so learners should review the [data desk card](/resources/data-desk-card) before class and use the live session for a focused combined case. Session 12 brings the course together through review, the knowledge assessment, a practical evaluation, Q&A, and recognition; the secure assessment may be scheduled separately if needed.
