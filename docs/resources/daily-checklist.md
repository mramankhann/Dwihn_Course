# Daily AI checklist

Use this before every AI-assisted DWIHN task. The current DWIHN catalog and policies control real work.

## Before input

1. **Purpose:** What task am I trying to complete, and who owns the result?
2. **Classification:** What is the highest tier in the prompt, attachment, screenshot, transcript, or linked source?
3. **Approval:** Is the exact tool, account, feature, data class, user role, and purpose allowed in the current catalog?
4. **Minimum input:** Can I accomplish the task with less data or a synthetic example? Follow DWIHN and privacy guidance on what is necessary for this purpose.
5. **Stop rule:** If any approval or data question is unclear, pause and ask the designated owner.

## Before output is used

6. **Facts:** Compare names, dates, measures, policy text, and claims against trusted sources.
7. **Human judgment:** Does a qualified person need to assess clinical, crisis, rights, or operational implications?
8. **Audience:** Does the draft contain information the recipient is allowed to see? Check small cells and link permissions.
9. **Documentation:** Record edits, approval, and the source of key facts using the normal workflow.
10. **Incident:** If data went to the wrong place or an output caused a possible issue, stop further sharing and report promptly through current DWIHN channels.

> **Memory cue:** Classify → Confirm → Review. A fast answer never replaces these checks.
