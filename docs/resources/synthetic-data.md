# Synthetic analytics practice data

**All numbers on this page are invented for teaching.** ZIP codes are real geographic labels used only to make the exercise readable; these figures describe no DWIHN members or actual performance. Do not combine this table with live records.

## Measure definition for this exercise

**Illustrative seven-day follow-up rate** = `number of qualifying synthetic discharges with a completed follow-up within seven days ÷ number of qualifying synthetic discharges` for the same period and program. “Qualifying,” “completed,” and the calendar rule are assumed for this exercise. They are **not** DWIHN's official measure specification.

| ZIP code | Prior quarter: completed / eligible | Prior rate | Current quarter: completed / eligible | Current rate |
|---|---:|---:|---:|---:|
| 48201 | 78 / 100 | 78.0% | 80 / 100 | 80.0% |
| 48202 | 70 / 90 | 77.8% | 66 / 90 | 73.3% |
| 48205 | 71 / 110 | 64.5% | 65 / 110 | 59.1% |
| 48224 | 79 / 100 | 79.0% | 81 / 100 | 81.0% |
| **Total** | **298 / 400** | **74.5%** | **292 / 400** | **73.0%** |

The current overall rate is 1.5 **percentage points** lower than the prior quarter. The table alone cannot establish why. A responsible investigation would check source completeness, discharge mix, scheduling process, date definitions, and whether the trend persists. A ZIP-level difference may reflect access barriers, recording practices, case mix, or chance; it is a **question for investigation**, not a judgment about residents or staff.

## Weekly subset for measure interpretation

| Week | Completed | Eligible | Rate |
|---|---:|---:|---:|
| 1 | 55 | 80 | 68.8% |
| 2 | 68 | 100 | 68.0% |
| 3 | 42 | 60 | 70.0% |
| 4 | 84 | 120 | 70.0% |

The completed count rises from 42 to 84 between Weeks 3 and 4, but the rate remains 70.0% because the eligible count doubles too. Use this to distinguish **volume** from **performance rate**.
