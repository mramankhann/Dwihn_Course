# Glossary

| Term | Plain-language meaning |
|---|---|
| **AI** | Software that learns or uses patterns to predict, classify, generate, or recommend. |
| **Generative AI** | AI that creates text, images, or other content from patterns and supplied context. |
| **Hallucination** | A plausible-looking AI claim that is unsupported or false. |
| **Automation bias** | Trusting a machine output too readily because it looks polished or objective. |
| **PHI / ePHI** | Protected health information / electronic protected health information under HIPAA. |
| **Business associate agreement (BAA)** | A HIPAA contract that sets permitted activities and safeguarding obligations for a business associate. |
| **Data tier** | An organization's label for sensitivity and handling requirements; this course uses the proposal's four provisional labels. |
| **Approved tool catalog** | DWIHN's current list of permitted AI tools, features, accounts, purposes, and data classes; not supplied with the proposal. |
| **Prompt** | An instruction and context given to an AI system. |
| **Numerator / denominator** | The counted outcomes / eligible population used to calculate a rate. |
| **Percentage point** | The arithmetic difference between percentages, e.g., 74.5% to 73.0% is 1.5 percentage points. |
| **Small cell** | A table group with few people that may create disclosure risk; DWIHN's threshold must govern release. |
| **Sentiment signal** | An AI estimate of emotional tone in an interaction; it is not a diagnosis. |
| **Governed data** | Data with defined ownership, access, measures, quality checks, and permitted use. |
| **Human-in-the-loop** | A workflow where a person reviews and is accountable for AI-assisted output or decisions. |
